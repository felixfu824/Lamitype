# Lamitype v0.5.19

## 繁體中文

- **浮動視窗邊角修正。** 聽寫指示器、翻譯與校對卡片、即時字幕等浮動視窗，不再出現方形灰色邊角。感謝 @ohong 回報並修正（#34）。

**更新方式：** 退出 Lamitype，從 DMG 將 `Lamitype.app` 拖到 Applications 取代舊版，再重新開啟。設定與已下載的模型會保留。

## English

- **Cleaner floating windows.** The dictation indicator, translation and polish cards, Live Caption and other floating windows no longer show square grey corners. Thanks to @ohong for spotting and fixing this (#34).

**Update:** quit Lamitype, drag `Lamitype.app` from the DMG into Applications to replace the old app, then relaunch. Settings and downloaded models are preserved.
