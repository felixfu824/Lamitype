# Lamitype v0.5.15

## 繁體中文

新增「即時預覽（實驗功能）」：按住右側 ⌥，邊說邊看草稿；放開後，貼上最終文字。

- 錄音條上方會定期更新辨識草稿，草稿可能改變。只有錄音結束後的最終文字會插入。

[![Lamitype 本機即時預覽實錄](https://lamitype.com/assets/asset-1-zh-tw-live-v2.png)](https://lamitype.com/assets/asset-1-zh-tw-live-v2.mp4)

- **每段即時錄音最多 60 秒。** 可提早放開。首次使用會先顯示提醒，可選擇不再顯示。較長的連續錄音請使用標準模式。
- **選單與設定共用同一套聽寫模式。** 從「聽寫模式」或「設定 → 語音輸入」選擇「本機 → 即時預覽（實驗功能）／標準」，或「雲端 → OpenAI／Gemini」。
- **即時預覽可能使用較多記憶體。** 即時模式在錄音期間會持續更新辨識草稿，記憶體峰值可能高於標準模式。若感到系統負載過高，可切換回標準模式。

**更新方式：** 退出 Lamitype，從 DMG 將 `Lamitype.app` 拖到 Applications，取代同一位置的 App，再重新開啟。設定與已下載的模型會保留。

## English

New **Live preview (Experimental)**: hold Right Option to see drafts as you speak; release to paste the final text.

- Recognition drafts refresh periodically above the recording bar and may change. Only the final result is inserted after recording ends.

[![English dictation with Lamitype Live preview](https://lamitype.com/en/assets/hero-live-preview-v2.png)](https://lamitype.com/en/assets/hero-live-preview-v2.mp4)

- **Up to 60 seconds per Live recording.** Release early to finish. A reminder appears on first use, with an option not to show it again. Use Standard for longer uninterrupted recording.
- **One Dictation mode menu, shared with Settings.** Choose **Local → Live preview (Experimental) / Standard**, or **Cloud → OpenAI / Gemini**, in **Dictation mode** or **Settings → Dictation**.
- **Live preview may use more memory.** Live mode updates recognition drafts during recording, so peak memory use may be higher than in Standard mode. If your Mac feels overloaded, switch back to Standard.

**Update:** quit Lamitype, drag `Lamitype.app` from the DMG into Applications and replace the app at the same location, then relaunch. Settings and downloaded models are preserved.
