# Lamitype v0.5.15 — Local Live preview

Release candidate · build 52 · Apple Silicon · macOS 15+

**Status: source prepared; public Developer ID signing, notarization and a real public-build upgrade permission check remain required. No public installer has been published.**

## English

- **See draft text while dictating locally.** Hold Right Option for a periodically refreshed preview above the existing recording bar. Both panels use the existing color palette and remain visually separate. Drafts can change; only final text is inserted.
- **Live preview defaults on when no mode choice exists.** Saved Standard/Live and cloud-engine choices are preserved. The first unconfirmed hold shows the 60-second reminder before capture; confirm, release, then hold again. The reminder also appears when enabling Live, with a **Don't show again** checkbox.
- **One Dictation mode menu, shared with Settings → Dictation.** Choose Local → Live preview (Experimental) / Standard, or Cloud → OpenAI / Gemini. Use Standard for longer uninterrupted recording. Cloud keeps its existing recording and consent flow.
- **A clear 60-second recording limit.** Release early or let the progress bar fill. Lamitype then recognizes the full captured recording once. Release the key before starting another recording; there is no automatic continuation.
- **Conservative automatic paste.** Live pastes only when the original text field is still verified. Otherwise, a brief notice points to **Last Live Result…** for Copy. Completed results do not open a window automatically.
- **Recover a failed final transcription.** Retry locally, explicitly save a WAV, or discard the recording. Only one failed recording is retained in RAM. Successful retry clears that audio and offers Copy rather than automatic paste.
- **Existing text processing stays in place.** OpenCC applies to previews and final results; final text retains the ordinary post-processing pipeline. Hotkey interruption and recovery-window handling are hardened.

Live is experimental periodic recognition, not token-by-token streaming. Earlier draft blocks may disappear; the final pass covers the captured recording. Recognition errors remain possible. Stop local microphone captions before starting Live dictation.

Live temporarily uses a **128 MiB idle MLX allocator cache**, restoring the previous policy after inference drains. This is not a total RAM limit; full-minute tests exceeded 2 GiB. No audio is saved automatically. App-held Live audio/results are cleared on quit, sleep or detection of Secure Input; clipboard text, pasted text and explicitly saved WAV files remain.

## 繁體中文

- **本機聽寫時即可查看草稿。** 按住右側 ⌥，原本錄音條上方會定期更新辨識預覽。上下兩個面板沿用既有配色並清楚分離。草稿可能改變，只有最終文字會插入。
- **尚未儲存模式選擇時，預設開啟即時預覽。** 已儲存的標準／即時模式與雲端引擎選擇會保留。第一次尚未確認的長按會先顯示 60 秒提醒，不會收音；確認並放開後，再次按住即可錄音。開啟即時預覽時也會顯示提醒，可勾選「不再顯示這則提醒」。
- **聽寫模式選單與「設定 → 語音輸入」同步。** 可選「本機 → 即時預覽（實驗功能）／標準」或「雲端 → OpenAI／Gemini」。需要更長時間的連續錄音時請選標準模式。雲端保留原有錄音與同意流程。
- **明確的 60 秒錄音上限。** 可提早放開，或等待進度條填滿；結束後會對整段錄音辨識一次。須先放開按鍵，才能開始下一段，不會自動接續。
- **謹慎處理自動貼上。** 只有原始文字欄位仍可驗證時才會貼上；否則短暫提示，請從「上次即時辨識結果⋯」複製。完成結果不會自動彈出視窗。
- **最終辨識失敗時可復原。** 可重新辨識、明確儲存 WAV 或捨棄；記憶體只保留一段失敗錄音。重新辨識成功後會清除音訊，並提供複製，不會自動貼上。
- **沿用既有文字處理。** 草稿與最終文字皆套用 OpenCC，最終文字維持原有後處理流程；同時改善快捷鍵中斷與復原視窗的可靠度。

即時預覽仍為實驗功能，採定期辨識，並非逐 token 串流。較早的草稿區段可能隱藏，最終辨識仍涵蓋整段錄音，辨識錯誤仍可能發生。使用前請先停止使用麥克風的本機即時字幕。

即時模式暫時將 **MLX 閒置配置器快取設為 128 MiB**，辨識工作結束後還原先前設定。這不是總 RAM 上限，完整一分鐘測試曾超過 2 GiB。不會自動儲存錄音；結束 App、睡眠或偵測到安全輸入時會清除 App 持有的即時錄音與結果，剪貼簿、已貼上的文字與明確儲存的 WAV 不受影響。

## Validation and remaining release gates

Verified on a 24 GiB M3 MacBook Air:

- Final automated regression: 282 tests, 10 optional skips, 0 failures.
- Native hotkey/reminder, Live/Standard, full-minute cap, paste/focus safety, Save/Retry/Discard, bundled OpenCC and packaged-app tests passed.
- Five human Mandarin/English code-switching clips exercised the capture-to-result path; delivery passing does not certify transcription accuracy.
- Packaged release-configuration soak: two warmups and 50 measured recordings, all deliveries accepted. Settled physical footprint 939.8–941.3 MiB; last-three versus first-three median growth about 1 MiB. One repeated human clip and 10-second idle intervals; this is not a memory guarantee or a days-long natural-use test.
- Serialized v0.5.13/v0.5.14 settings and support-file migration checks passed; cached-model offline reuse passed separately.

Before public distribution, follow [the release procedure](../RELEASING.md): Developer ID sign, notarize, staple, validate Gatekeeper, and test an actual public-build upgrade without resetting permissions. The locally installed Apple Development build cannot prove that upgrade path. Paid cloud-provider requests, 8 GiB hardware, Bluetooth microphones and broad third-party field compatibility are not certified by this test run.
